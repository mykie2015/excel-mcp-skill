# PRD: Excel MCP Skill for Codex

## 1. Overview

Build an agent skill (`excel-mcp-skill/`) that enables Codex (or any compatible agent) to manipulate Excel workbooks via MCP servers and Python libraries. The skill bundles instructions, scripts, and configuration to handle common Excel automation tasks: reading/writing cells, formatting, pivot tables, chart generation, data validation, and cross-workbook operations.

## 2. Goals

- Create a production-ready skill at `excel-mcp-skill/SKILL.md` following the Agent Skills spec
- Support two MCP server backends (Python: `haris-musa/excel-mcp-server`, TypeScript: `sbraind/excel-mcp-server`)
- Include Python library fallback path (openpyxl + pandas) for environments without MCP
- Provide scripts for common operations (data validation, format templates, workbook health checks)
- Include example workflows for realistic business use cases

## 3. Target Users

- Engineers who use Codex CLI to automate Excel-related tasks
- Teams that need repeatable Excel report generation
- Data analysts who want AI-assisted workbook manipulation

## 4. Non-Goals

- Building the MCP servers themselves (they already exist)
- Supporting Google Sheets (separate skill)
- GUI or web interface
